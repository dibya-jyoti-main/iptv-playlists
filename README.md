## 🔌 JSON API Reference

| Endpoint | Description |
|----------|-------------|
| [`/stats.json`](https://DibyaJyotiMahanta.github.io/iptv-playlists/stats.json) | Channel counts, top categories/languages/countries |
| [`/channels.json`](https://DibyaJyotiMahanta.github.io/iptv-playlists/channels.json) | Full channel list with metadata |
| [`/categories.json`](https://DibyaJyotiMahanta.github.io/iptv-playlists/categories.json) | All categories with counts & playlist links |
| [`/languages.json`](https://DibyaJyotiMahanta.github.io/iptv-playlists/languages.json) | All languages with counts & playlist links |
| [`/countries.json`](https://DibyaJyotiMahanta.github.io/iptv-playlists/countries.json) | All countries with counts & playlist links |
| [`/update.json`](https://DibyaJyotiMahanta.github.io/iptv-playlists/update.json) | Last update timestamp & status |
| [`/drm/drm.json`](https://DibyaJyotiMahanta.github.io/iptv-playlists/drm/drm.json) | DRM channel metadata |
| [`/drm/drm_keys.json`](https://DibyaJyotiMahanta.github.io/iptv-playlists/drm/drm_keys.json) | DRM KID → Key pairs |

### Example: stats.json
```json
{
  "totalChannels": 5230,
  "cleanChannels": 5110,
  "drmChannels": 120,
  "categories": 18,
  "languages": 22,
  "countries": 30,
  "lastUpdated": "2025-01-01T00:00:00.000Z",
  "generatedBy": "Dibya Jyoti Mahanta",
  "portfolio": "https://dibya-jyoti.vercel.app"
}
```

## ℹ️ Playlist Format

Every playlist uses the standard M3U format with rich IPTV metadata:

```m3u
#EXTM3U
#
# ==========================================
#  IPTV Playlist — Auto Generated
# ==========================================
#  Playlist Name : NEWS PLAYLIST
#  Total Channels: 342
#  Last Updated  : Mon, 01 Jan 2025 00:00:00 GMT
#  Generated By  : Dibya Jyoti Mahanta
#  Portfolio     : https://dibya-jyoti.vercel.app
# ==========================================
#
#EXTINF:-1 tvg-logo="https://..." group-title="News" tvg-language="English",BBC News
https://stream.example.com/bbc-news/index.m3u8
```

Compatible with: **VLC** · **TiviMate** · **IPTV Smarters Pro** · **GSE Smart IPTV** · **Kodi (PVR IPTV Simple)** · **OTT Navigator** · **Perfect Player**
